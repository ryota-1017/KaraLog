> **「自分だけのカラオケ選曲データベース ＆ 現場特化型アシスタント」**  
> 装飾を極限まで削ぎ落とした、Instagram / Threads スタイルの静謐で都会的なカラオケ記録アプリ。  
> 完全ローカル保存（SQLite / Room DB）により、通信費ゼロ・サーバー代0円・完全プライベートで利用できます。

---

## 🌟 特徴とデザイン仕様

### 1. 📐 Tactile 3D × Rounded Modern Design（立体的で丸みを帯びたおしゃれなデザイン）
- **フローティング・アイランド（Bottom Nav）**: 画面下部からふわりと浮いたカプセル型アイランドドック（角丸32dp）を採用。
- **立体的なフローティングカード**: 楽曲リスト、ランキング、履歴カードを角丸18dpの立体カードへ全面リニューアル。柔らかなシャドウと微細ハイライトで上品な奥行きを演出。
- **ぷっくりとした丸みピルボタン＆フィルター**: 検索バー（角丸26dp）、機種・カテゴリフィルター、キー調整ボタン（`[-]`/`[+]`）など、あらゆる操作部を心地よい丸みのピル・サークル形状に統一。
- **立体モーダル＆テンキー**: 採点入力や確認ダイアログも角丸24〜28dpのふっくらとした立体ダイアログに進化。
- **厳格なモノトーンパレット**: True Black / Soft Slate を基調とし、ノイズを排した大人のデザイン。
- **Edge-to-Edge 完全対応**: ステータスバー（時計・カメラノッチ）やナビゲーションバーとの重なりを自動解消。

### 2. ⚡ 直感的なホーム画面（手書きスケッチの完全再現）
- **ストーリーズ風 クイックアクショントレイ**:
  - `[🔍 検索]` `[🎤 歌唱]` `[🕒 履歴]` `[➕ 追加]` が円形サークルで並び、ワンタップでアクセス可能。
- **オススメ曲リスト**:
  - 正方形のミニマルサムネイル、曲名、アーティスト名、オプションメニュー（`⋮`）をタイトに配置。
- **過去のランキング**:
  - 順位バッジ（`1.`）、アルバムアート風サムネイル、歌唱日付、機種別スコア（`98.1 精密採点AI`）を一目で確認。

### 3. 🎯 カラオケ現場に特化した実用機能
- **カラオケ予約ストックリスト（順番入れ替え機能）**: 「次に歌う曲」を何曲も予約・ストックでき、ホーム画面で「▲」「▼」で歌う順番を直感的に入れ替え。
- **曲の削除機能**: 楽曲カードや検索一覧のゴミ箱ボタンからいつでも不要な曲を削除（確認ダイアログ付き）。
- **「Start Karaoke」画面（機種選択）**: 入室時にDAM / JOYSOUNDを選択してカラオケセッションを開始。「ライブラリ閲覧」時も右上の「Start」ボタンからいつでも開始可能。
- **ヘッダーの「Finishロゴ」**: 設定ロゴの左隣からいつでも本日のセッションを終了・サマリー確認可能。
- **深夜3時の自動セッションリセット**: 深夜3時（3:00 AM）を跨ぐと自動でセッションが締め切られ、退室忘れを防止（設定からON/OFF可能）。
- **YouTube Music / Spotify 原曲試聴連携**: 1タップで原曲・公式PVをアプリ内から起動。
- **人気ランキング定番35曲のプリセット登録**: 怪獣の花唄、ドライフラワー、残酷な天使のテーゼ等の人気曲を初期搭載。
- **キー・予約番号メモ**: 曲ごとに自分に合ったキー（`±0`, `+2`, `-1`）やデンモク予約番号を記録。
- **スマートテンキー採点入力**: `94821` と打つだけで自動的に `94.821` にフォーマットされる快速入力。
- **DAM / JOYSOUND 対応フラグ**: 機種ごとの配信状況や採点結果をスマートに管理。

### 4. 🔒 完全ローカル・プライバシー保護
- すべてのデータはお手元の端末内（Room SQLite）にのみ保存されます。
- アカウント登録不要、ログイン不要、外部通信なし。
- 電波の届きにくい地下のカラオケボックスでも爆速・快適に動作します。
