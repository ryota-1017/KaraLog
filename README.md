> **「自分専用のカラオケデータベース ＋ 現場特化型選曲アシスタント」**  
> カラオケ現場での体験を徹底追求した、完全ローカル・通信費ゼロ・登録不要のAndroidアプリです。

---

## 🌟 主な機能

### 1. 🎤 現場最優先の体験フロー（Now Singing）
- **入室時に機種選択**: DAM（精密採点Ai 等）/ JOYSOUND（分析採点Ai 等）をワンタップ選択。
- **特大タイポグラフィ待機画面**: 薄暗い部屋やテーブルからでも一目で曲名・アーティスト名・キー設定が確認可能。
- **スマート点数入力（テンキー）**: 小数点自動アシスト機能により、`94821` と打つだけで自動で `94.821` にフォーマット。2秒で記録完了。
- **リベンジ（もう1回歌う）ボタン**: 悔しい時や調子が良い時に、同じ曲・同じキー設定のままワンタップで再待機状態へ。

### 2. 📱 Material 3 Expressive ＆ OLED Dark デザイン
- **OLED Dark (ミッドナイトネイビー)**: 暗いカラオケルームでも眩しくない目に優しいハイコントラスト配色。
- **心地よい触覚フィードバック (Haptic Vibrations)**: ボタンタップ、テンキー入力、自己ベスト更新時に指先へ確かなクリック感が伝わります。
- **滑らかな画面遷移アニメーション**: ページスライド、クロスフェード、ピル伸縮スプリングモーション。

### 3. 🔍 スマート曲管理 ＆ 視聴連携
- **本日の歌唱候補カルーセル**: カラオケに行く前の電車や家でキープ（ピン留め）した曲がホーム最上段に並び、部屋に入ったら即歌える。
- **DAM / JOYSOUND 配信フィルター**: 各機種への配信状況が一目でわかるバッジ表示。
- **Spotify / YouTube Music 視聴**: 各曲カードからワンタップで公式音源を試聴可能。
- **キー微調整ステッパー**: `[−]` `原曲` `[＋]` で直感的にキーを変更・保存。
- **デンモクリクエスト予約番号メモ**: 番号を保存しておけば、デンモクの数字キーで一瞬で予約完了。
- **超速クイック追加**: 検索で見つからない新曲やマイナー曲も、曲名を入れてそのまま即歌唱！

### 4. 📊 過去のまとめ ＆ 終了時リザルトカード
- **カラオケ終了サマリーカード**: 「終了」を押すと本日の歌唱曲数、平均点、最高得点、MVP曲を発表！
- **自己ベストランキング**: 過去の通算記録や機種別の最高得点ランキングを一覧化。

### 5. 🔒 完全ローカル保存（安心・安全・無料）
- すべてのデータは端末内の SQLite（Room DB）にのみ保存されます。
- 外部サーバーへの通信は一切なく、**サーバー維持費・通信費は一生0円**。
- アカウント登録・ログイン不要。電波の届きにくい地下の部屋でも爆速で動作します。

## 🚀 ビルド & 実行方法

### 前提条件
- JDK 17 以上 (JDK 21 推奨)
- Android SDK (API 35, Build-Tools 35.0.0)

### APKビルドコマンド
```bash
./gradlew assembleDebug
```
出力先: `app/build/outputs/apk/debug/app-debug.apk`
